# Priora

Plan. Prioritize. Progress.

Priora is a productivity platform designed to help users manage tasks, deadlines, reminders, goals, schedules, and unfinished work in one place.

## Tech Stack

### Frontend
- Flutter
- Riverpod
- GoRouter

### Backend
- FastAPI
- PostgreSQL
- Supabase

### Notifications
- Firebase Cloud Messaging
