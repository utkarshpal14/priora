# Project Versioning & Release Rules

## Strict Version Number Policy
- **DO NOT change or bump version numbers** anywhere in the project (including `frontend/pubspec.yaml`, `backend/app/core/config.py`, `docs/`, or any other config) unless the user **EXPLICITLY** asks to bump or publish a new version.
- When working on new features, bug fixes, or enhancements, always keep the currently designated version intact unless explicitly instructed otherwise by the user.
