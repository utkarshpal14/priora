# Document 06 — UI UX Architecture & Wireframes

## 1. Design Principles

Lock these first.

### DP-001

Mobile First

Priora is primarily an Android app.

### DP-002

Fast Task Entry

**Creating a task should take:**

< 30 seconds

### DP-003

Minimal Clicks

**Most actions:**

≤ 3 taps

### DP-004

Important Things Visible

**Always show:**

- Today's Tasks
- Upcoming Deadlines
- Pending Tasks
